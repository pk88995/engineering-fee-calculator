# 工程費用覆核工具 v1.1

以新臺幣元輸入工程金額，試算工程相關費用，供工程經費編列與會計覆核參考。

## 使用方式

透過本儲存庫的 GitHub Pages 網站使用，或下載 `index.html` 後，以瀏覽器開啟。單一 HTML 檔案已內嵌計算程式與參考文件，可離線使用，無須安裝套件。

## 計算項目

- 承包商工地管理費與利潤、品管費及環保費。
- 工程管理費，包含全部自辦時的相關加計。
- 公共工程（非建築物）與建築物工程的技術服務費及折扣試算。
- v1.1 新增「其他營建工程」的營建工程空氣污染防制費試算，支援第一級、第二級及第三級費率與認可扣除額。

空氣污染防制費的費率等級位於左側輸入區，排列在技術服務費折扣率下方。

## 版本與依據

目前版本：**v1.1**。公開版保留原先完成的 v1.1 HTML 內容。

費率與適用說明依原始工具內嵌的參考文件；本版涵蓋新北市間接工程費用編列原則（115 年 5 月 28 日）、工程管理費及工作費編列支用要點（115 年 8 月 25 日）、技術服務費百分比參考表，以及營建工程空氣污染防制費收費費率表等文件。工具中的參考數值仍應配合個案條件、契約及適用規定確認。

## 驗證

已通過 596 項計算精度、級距邊界、輸入驗證及整合檢查。

```sh
npm test
```

測試僅使用 Node.js 內建模組，無額外依賴。
